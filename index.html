The evidence path

A result is only as strong as the path beneath it.

The same signal continues through four chapters. Each chapter adds evidence without silently changing its meaning.

Chapter I

Ask a bounded question.

Start with a decision that evidence can actually change: a route contract, a sensitivity range, a provenance gap—not “solve satellite networks.”

See the research map
Chapter II

Name the source.

A paper, standard, public dataset, or generated fixture gets a role and an evidence tier. A linked repository remains an artifact route until it is inspected and executed.

Browse curated sources
Chapter III

Run the smallest useful check.

Deterministic validators, route-aware contracts, and bounded synthetic fixtures test one mechanism at a time. Trace evidence matters more than a polished final answer.

Inspect the fixture case study
Chapter IV

Keep the non-claim visible.

Fixture integrity is not model performance. A paper report is not a Nimbus reproduction. A successful local run is not deployment authorization.
