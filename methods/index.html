A claim should fit
its evidence.

Nimbus uses narrow labels for evidence so a local check does not quietly become a broad public claim.

NX/EVIDENCE-LADDER4 TIERS
01 / source note
02 / local check
03 / reproducible artifact
04 / deployment evidence

Source note

A cited paper, standard, or public dataset. It can motivate a question; it does not prove Nimbus reproduced the result.

Local check

A deterministic test, parser, validator, or fixture audit executed in the local research environment.

Reproducible artifact

A versioned public input, method, and expected result that another reader can inspect and attempt to run.

Release rules

INCLUDE

Sanitised summaries, public sources, synthetic fixtures, aggregate results, explicit limitations, and versioned methods.

EXCLUDE

Credentials, private mail, private chats, raw logs, user documents, unreviewed sensitive data, and live-control material.

CORRECT

When a public claim changes, update the page with a dated changelog note rather than silently rewriting the conclusion.
